## 安装教程 Setup Instructions

在这次教程中，我们为参与者提供了一个 [code-server](https://github.com/coder/code-server)，您只需要一台带有网络浏览器的笔记本电脑即可参与。  
In this tutorial, we're hosting a code-server for our participants, the only thing you need is a laptop with a web browser to take part in.

下面是上手步骤：  
Here are steps to get started:

1. 在浏览器中打开 <https://bootcamp.xiangshan.cc>。  
   Open <https://bootcamp.xiangshan.cc> in your browser.
2. 输入密码：**将在现场公布**  
   Enter password: **TO BE DISCLOSED ON SITE**
3. 默认情况下，您应该会看到一个终端。  
   By default you should see a terminal
    - 如果没有，请点击左上角的菜单（三个横线），然后选择 “Terminal > New Terminal”以打开一个新的终端。  
    If not, click Menu (triple dashes) on the top-left corner, then "Terminal > New Terminal".
4. 在终端中运行 `./start.sh`。  
   Run `./start.sh` in the terminal.
    - 这将为您创建一个唯一的随机 ID，并在 `/data/${random_id}` 下创建您的工作空间。  
    This will create a unique random id for you, and create your workspace at `/data/${random_id}`.
5. 当您的工作空间创建完成后，它应该会自动打开。  
   When your workspace is created, it should be opened automatically.
    - 如果没有，请点击“Menu > File > Open Folder”，输入 `/data/${random_id}`，然后点击“OK”。  
    If not, click "Menu > File > Open Folder", enter `/data/${random_id}`, then click "OK".
6. 如果您在任何时候遇到问题，请随时向相关人员寻求帮助。  
   Feel free to ask the instructors for help any time if you have any problem.
