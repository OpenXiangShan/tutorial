# 2026 RISC-V 中国峰会教程主题详情

本教程将在 2026 RISC-V 中国峰会同期活动中举行。活动时间为 **2026 年 10 月 20 日（星期二）10:40 起**（具体时间以现场安排为准），地点为**深圳市会展中心（福田）6 层桂花厅**。

## XS-GEM5与实践环节

香山现已配备了一款经过校准的软件模拟器——XS-GEM5，它是旨在支持架构探索与开发的集成工具链的重要组成部分。本次分享将涵盖以下内容：

- XS-GEM5 的背景介绍与设计初衷。
- XS-GEM5 的架构设计及其与“香山”处理器的校准机制。
- 用于提升开发效率的相关工具。
- 利用 XS-GEM5 进行架构研究的实操演示。

如需参加实践环节，请参阅[实践环境搭建说明](./hands_on/setup.md)。

## 香山开发工作流与实践环节

为了加快香山的开发，以及功能验证和性能验证流程，我们构建了一套名为 MinJie 平台的开源开发基础设施。本环节将使用基于 Code-Server 和 Jupyter Notebook 构建的 XiangShan-bootcamp，直观演示如何基于香山与 MinJie 平台开展开发工作。听众可以亲自尝试以下步骤：

- 搭建香山开发环境。
- 配置并构建香山。
- 使用 Verilator 运行香山仿真。
- 使用 MinJie 调试香山，包括 NEMU、difftest、lightSSS 等工具。
- 使用 MinJie 评估香山性能，包括 XSPerf、Top-down 等工具。

我们还将介绍 MinJie 平台中各项工具的设计动机与要点，并展示如何基于香山与 MinJie 平台复现多项体系结构研究成果，促进学术界与工业界之间的交流。

## XSAI（香炉峰）

XSAI（香炉峰）是北京开源芯片研究院面向当今 AI 推理场景与Agentic 场景，基于香山昆明湖开发的开源 AICPU。本环节将会讲解 XSAI（香炉峰）的开发理念，介绍基于香山进行定制化开发的优势，以及 XSAI（香炉峰）提供的 AI 原生基础设施。本环节还展示了 XSAI（香炉峰）在 FPGA 云平台上的运行，在 OpenRUYI 上推理大语言模型。

如需参加实践环节，请参阅[实践环境搭建说明](./hands_on/setup.md)。
